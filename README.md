# 🌍 Renewable Energy Weather App

An Android app that provides **real-time weather forecasts** and calculates the **optimal renewable energy source (Solar, Wind, or Hydro)** for a given location using live weather data.  

---

## 📱 Features

- 🌤️ **Weather Forecast**
  - Current temperature, humidity, wind speed, and more
  - Hourly forecast for the next 6 hours
  - Daily summary (sunrise, sunset, precipitation, moon phase, etc.)

- ⚡ **Energy Source Calculation**
  - Analyzes solar radiation, UV index, cloud cover, wind speed, precipitation, and more
  - Calculates a **confidence score** for:
    - ☀️ Solar Energy
    - 💨 Wind Energy
    - 💧 Hydro Energy
  - Recommends the **best renewable source** for your location with practical suggestions

- 🌍 **Global Support**
  - Search by city name, small town, village
  - Works with coordinates, airport codes, and postal codes

## 🛠️ How It Works  

1. Enter a location in the search box  
2. Tap **🌤️ Get Weather** → Fetches weather data and displays it in detail  
3. Tap **⚡ Energy Source Calculation** → Calculates which renewable source (Solar/Wind/Hydro) is most efficient for that location
